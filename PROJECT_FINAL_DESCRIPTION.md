# Version finale du projet

Ce projet implémente un système de formalisation automatique du besoin XR industriel à partir d’un texte utilisateur.

Il extrait :

1. **Contexte d’utilisation**
   - type de XR : VR, AR, MR ;
   - domaine : Conception, Production, Maintenance ;
   - activités : Visualisation, Formation, Simulation, Assistance, Guidage procédural, Assemblage, Démontage, Contrôle qualité, Inspection, Diagnostic, Mesure, Calibration, Réparation, Remplacement, Prototypage virtuel, Revue collaborative, Évaluation ergonomique, Planification d’implantation, Optimisation des flux, Navigation, Localisation et tracking, Logistique, Capture de mouvement, Analyse et aide à la décision.

2. **Environnement immersif**
   - capture du hardware explicitement mentionné ;
   - proposition du hardware si absent ;
   - recommandation dépendante de XR + domaine + activité.

3. **Scènes et objets virtuels**
   - scène principale ;
   - objets 3D principaux ;
   - sous-composants ;
   - petits composants ;
   - outils ;
   - éléments virtuels XR ;
   - objets inconnus à confirmer.

4. **Environnement réel**
   - détection de l’interaction avec le réel ;
   - objets réels concernés ;
   - types d’interaction : superposition, reconnaissance, scan, ancrage, alignement ;
   - relations réel-virtuel.
